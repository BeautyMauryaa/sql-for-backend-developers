## DDL - DATA DEFINATION LANG
- define and modifies database structue
CREATE ALTER DROP TRUNCATE


## DML - data manipulation lang
- modifies record inside tables
INSER UPDATE DELETE

## DQL - QUERY LANG
- retrive data
SELECT

## DCL-data control lang
- control database permission
GRANT REVOKE

## TCL - transaction control lang
- manage transactions
COMMIT, ROLLBACK, SAVEPOINT
